# TonTon P2PGuard privacy policy

TonTon P2PGuard processes network information on your Mac. It does not send your traffic, network endpoints, app activity, or blocking records to the developer and does not include advertising or analytics.

To apply a rule, the network filter examines connections for the app covered by that rule. The filter does not save packet contents. The optional connection observation setting shows recent app names, destinations, and byte counters. Recent connections and blocking decisions are kept in memory and are shared only with the signed TonTon P2PGuard app for the corresponding Mac user. The network speed and history shown in the menu bar come from local interface counters. Aggregate rates by interface are saved on your Mac for up to seven days. No destinations or app activity are saved in those aggregates. Rules and preferences are saved locally by macOS.

If you choose to check your public IP address, the app makes an HTTPS request to [ipify](https://www.ipify.org/), which sees your public IP address to return it. This request runs only when you ask for it. The optional latency test opens a TCP connection to the host and port you choose; that destination can see your IP address. The app does not send application data during that test. If you follow a link to GitHub for support, GitHub handles that visit under its own privacy terms.

For privacy questions, contact the developer through the [project’s GitHub support page](https://github.com/widmonstertony/thunder-guard/issues). Avoid including private traffic details in public issues.
